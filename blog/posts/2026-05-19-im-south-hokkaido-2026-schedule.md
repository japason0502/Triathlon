## Part 2：4日間スケジュール

### 9月11日（金）：函館入り＆選手受付

```
10:50 HND発（飛行機）
12:10 HKD着
13:00 函館駅着
13:30 函館アリーナへ移動
       （函館駅前 → 市電「湯の川」or タクシー15分）
14:00 選手受付（〜17:00受付可能）
       周辺でランチ
15:00 選手説明会（日本語セッション・参加必須）
16:00 説明会終了
夕方   宿に戻る → 3種類のバッグ
       （青：バイク用／赤：ラン用／黒：着替え）を
       パッキング
```

**ポイント：**
- 選手受付の会場は **函館アリーナ**（2025年大会から函館市民会館 → 函館アリーナの可能性あり、要アスリートガイド確認）
- 説明会は日本語セッションと英語セッションが分かれる
- 翌日のバッグパッキングはこの日のうちに完了させておく

### 9月12日（土）：T1/T2預託＆試泳

この日のキモは **「重いバイクを真っ先に手放す」** こと。

```
09:30 函館の宿を自走で出発
       （バイクに「青」と「赤」を背負って）
10:15 T1（上磯漁港）到着
       約11km・40分目安
       ┗ アンクルバンド（計測チップ）受け取り
       ┗ バイク＋バイクギアバッグ（青）を預託
11:30 休憩・昼食
       （T1付近でリラックス）
13:00 公式試泳
       （本番と同じ海で感覚を掴む）
14:00 試泳終了
14:30 T1 → T2へシャトルバス移動
       ランギアバッグ（赤）持参
       移動時間 約40〜50分、バス30分間隔運行
15:30 T2（木古内町ふるさとの森公園）到着
       ┗ ランギアバッグ（赤）を預託
16:20 T2 → 函館へシャトルバス
       木古内駅北口 → 函館駅前
       移動時間 約1時間
17:20 函館駅着 → 宿に戻る
       早めの夕食 → 早寝
```

#### 預託時間制限

| エリア | 預託時間 |
|---|---|
| T1（上磯漁港西側） | 10:00〜17:00（バイク・青バッグ・アンクルバンド） |
| T2（木古内町ふるさとの森公園） | 10:00〜17:00（赤バッグ） |

**ポイント：**
- 自走11kmは輪行解体・組立を考えると逆に楽。函館駅前 → 上磯漁港は走りやすい平坦路
- 試泳は本番と同じ海域で感覚を掴む貴重な機会。波がある日も「本番想定」で泳ぐと当日メンタル安定
- T1→T2→函館のバス2本立てが地味に長い。トータル約2.5時間の移動

## Part 4：このスケジュールの考え方

### なぜ「9/12に先にT1自走→T2バス」なのか

選択肢としては以下の3パターン考えられます。

| プラン | 内容 | 評価 |
|---|---|---|
| A | T1まで自走 → T2まで自走（バイク2拠点制覇） | ✕ バイク2回預けに行く動線がない |
| **B（採用）** | **T1まで自走 → T2はバスで移動** | ◎ バイクを最速で手放せる |
| C | T1までシャトル → T2もシャトル | △ シャトルの時間に縛られる |

**Bが最も合理的な理由：**

1. **バイクを9/12の午前中に手放せる** → 残りの行動が身軽
2. **試泳は午後**なので、T1で休憩しつつ試泳に直行できる
3. **赤バッグはバスで運べる** → 体力消耗を最小化
4. **試泳後にT2へ行く動線が一気通貫** → 効率最大

### 黒バッグ（着替え）の流れに注意

| 当日朝（T1で預ける） | レース後（T2で受け取る） |
|---|---|
| 9/13 朝、T1でストリートギアバッグ（黒）を預ける | 9/13 夕方、フィニッシュ後に木古内小学校で受け取る |

→ **「朝預けた荷物がゴール地点に運ばれる」** という仕組み。
→ 含めるもの：フィニッシュ後の着替え、防寒具、靴、貴重品など。

### バイクは「事前輸送」が経験者のスタンダード

2025年大会の参加者ブログを見ると、ほぼ全員が **カンガルー便等で事前輸送** していました。

- 機内預けは「自転車を預けるために長蛇の列」「積み残し・出発遅延のリスク」
- 事前輸送なら **ホテル到着時にバイクが届いている** 状態を作れる
- レース後も **ホテルから直接返送** できる

## まとめ

IRONMAN南北海道2026の4日間スケジュール、考えるべきポイントは以下の5つです。

1. **シャトルバスは予約必須** → エントリー直後に押さえる
2. **宿は函館駅前** → 東横INNなど函館駅徒歩圏が動線最良
3. **9/12の動線は「T1自走→T2バス」が合理的**
4. **黒バッグは朝T1で預けて夕方T2で受取**
5. **バイクは事前輸送が経験者の定番**
